# AI Setup Template

Эта папка содержит все настройки, навыки, воркфлоу и контекст для инициализации AI агентов в новом проекте (Spec-Driven Development / SDD). 

## Как использовать в новом проекте:

1. Скопируйте все содержимое этой папки в корень вашего нового проекта.
2. Проверьте и обновите файлы в папке `context/`, чтобы они соответствовали новому проекту (например, `project_overview.md`, `architecture.md`, `ui_context.md`).
3. При необходимости отредактируйте `AGENTS.md` под специфику новой кодовой базы.

## Структура папки:

- **`.agents/`** - содержит все воркфлоу (`workflows/`) и навыки (`skills/`), которые агенты могут использовать для выполнения задач (анимации, дизайн, верстка, дебаггинг и др.).
- **`AGENTS.md`** - Главный файл правил и протоколов поведения агентов для кодовой базы. Агенты читают его перед тем, как что-либо менять.
- **`context/`** - Папка с описанием контекста проекта:
  - `ai_workflow_rules.md` — правила рабочего процесса ИИ.
  - `architecture.md` — архитектура проекта.
  - `code_standards.md` — стандарты кода.
  - `project_overview.md` — общее описание проекта.
  - `ui_context.md` — контекст по UI/UX и дизайну.
  - `expected_load.md` — ожидаемая нагрузка и SLA.
  - `progress_tracker.md` — файл трекинга текущих задач.
  - `api_specs/` и `feature_specs/` — папки со спецификациями фичей и API.
- **`.mcp.json`** - конфигурации MCP-серверов для агентов.
- **`skills-lock.json`** - лок-файл версий установленных навыков.
