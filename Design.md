# Design & UI/UX Principles

## 1. Философия
- **Content First:** Главное на экране — видеоплеер и субтитры. Интерфейс не должен отвлекать от изучения.
- **Clean & Minimal:** Минималистичный стиль, отсутствие кричащих элементов. Фокус на типографике и пространстве.
- **No AI Slop:** Строгий запрет на необоснованные градиенты, прыгающие тени, бесполезные 3D-эффекты и избыточные анимации.

## 2. Взаимодействие (Interaction Design)
- **Выделение текста:** Должно быть нативным, как при копировании текста. После выделения плавно появляется Popover/Tooltip с переводом.
- **Снятие блюра:** Происходит плавно (CSS transition), без резких скачков интерфейса.
- **Лимиты (Paywall):** При достижении лимита (100 переводов / 50 сохранений) пользователь видит понятное, элегантное модальное окно. Никаких агрессивных цветов — только честный призыв перейти на Premium.

## 3. Компоненты (Design System)
- **Доступность (A11y):** Использовать примитивы Radix UI для модальных окон, поповеров и дропдаунов.
- **Иконки:** Использовать набор `lucide-react`.
- **Стилизация:** TailwindCSS + `class-variance-authority` (CVA) для создания переиспользуемых вариантов компонентов (напр., кнопок).
