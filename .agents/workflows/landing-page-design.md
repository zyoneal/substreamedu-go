Build or optimize a high-converting landing page using eleyadesign's framework:

1. **Read & Activate Skill**:
   - Consult `.agents/skills/landing-page-design/SKILL.md`.
2. **Execute Part A (Strategy & Structure)**:
   - Clarify the single core offer, audience, and primary CTA.
   - Establish high-converting section sequence: Hero with immediate clarity, Social Proof, Core Value Prop, Interactive Feature Demo, Testimonials / Case Study, Pricing, FAQ, and Final Conversion Push.
3. **Execute Part B (Visual System)**:
   - Apply strict typography scale, intentional spacing, distinct corner radii, cohesive palette, and crisp iconography.
4. **Implement Production Code**:
   - Write clean, responsive, accessible React components with semantic HTML.
